Troubleshooting

Check the branch, remotes, and exact error before changing anything.

The commit is missing on GitHub

Check the current branch. Commit the staged file, then push or publish that branch.

The pull request shows no changes

Check the head repository, head branch, base repository, and base branch. Confirm that you pushed.

The quality check is waiting

First-time contributors may need an owner to approve the workflow run.

The reviewer picker is unavailable

Send the pull request URL to the reviewer and ask a team lead to assign them.

A push is rejected

Stop and inspect git status, the current branch, and git remote -v with an instructor.

There is a merge conflict

Read Current, Incoming, and Result. Keep the intended final content. Use Accept Both only when both changes belong.

Ask for help

Share the useful details

  • The action you attempted
  • The exact error message
  • The current branch
  • The repository URLs from git remote -v
Remove private information

Do not post tokens, email addresses, private repository names, or other personal information in a public issue or screenshot.
