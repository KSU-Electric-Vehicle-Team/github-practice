# KSU EVT GitHub practice

This public repository is a safe place to learn the club contribution workflow.
You do not need to join the KSU Electric Vehicle Team GitHub organization.

## What you will practice

- Forking a public repository
- Cloning your fork in VS Code
- Creating a branch
- Committing and publishing a change
- Opening a pull request
- Reading an automated check
- Responding to review

## Exercise

1. Sign in to GitHub and use **Fork** to create a copy under your account.
2. In VS Code, run `Git: Clone` and select your fork.
3. Install the recommended extension when VS Code offers it.
4. Create a branch named `practice-YOUR-GITHUB-USERNAME`.
5. Copy `practice/template.md` to `practice/YOUR-GITHUB-USERNAME.md`.
6. Replace every `TODO` in your new file.
7. Open the Source Control view, commit your change, and publish the branch.
8. Use **GitHub Pull Requests and Issues** to create a draft pull request back
   to this repository's `main` branch.
9. Check the `quality` result. Fix your file if it fails.
10. Mark the pull request ready and respond to the review.

The workflow that checks pull requests has read-only access and receives no
organization secrets. First-time contributors may need an owner to approve the
workflow run.

Stuck? Open a public issue with a screenshot and the exact error message. Remove
email addresses, tokens, and other private information before posting.
